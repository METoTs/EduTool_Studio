# EduTool Studio 작업 목록 및 테스트 케이스

작성 기준: `에듀툴 녹화.zip`의 화면 이미지 24장과 현재 OBS Studio 기반 저장소를 검토한 결과. 이미지는 화면 제안 자료이며, 이미지에 적힌 개발 지시나 예시 값은 확정 사양으로 간주하지 않는다.

## 1. 범위와 원칙

- 메인화면에는 현재 상태, 미리보기, 주요 실행 동작, 해당 기능의 상세 화면으로 가는 진입점만 둔다.
- 메인화면의 공통 `설정` 내용과 별도 공통 설정 화면은 이번 작업 범위에서 제외한다.
- 녹화 품질·저장 위치, 카메라, 오디오, 소스, 라이브 연결, 업로드 옵션 등 **기능별 세부 설정**은 유지한다. 필요하면 기존 OBS 설정/속성 창을 해당 기능에서 연다.
- 이미지마다 레이아웃과 문구가 다르므로 기능 동작을 우선 정의하고, 화면 구성은 하나로 통일한다.
- 기존 OBS의 녹화·방송·소스·필터 기능은 재사용 범위를 확인한다. 타임라인 기반 **녹화 후 편집**은 OBS의 녹화 중 파일 분할 기능과 별개의 신규 기능이다.
- `D:\EduToolStudio`, Logitech BRIO, RODE NT-USB, 특정 계정·강좌·동영상은 예시 데이터다. 경로·장치·사용자 이름을 고정하지 않는다.

### 상태 표시 기준

아래 항목은 **구현 계획**이며 완료 표시가 아니다. 현재 코드에서는 OBS 녹화/방송 시작·종료, 녹화 폴더 열기, 소스 속성 및 필터의 기반을 확인했다. EduTool 전용 계정·홈페이지 연동과 타임라인 편집은 별도 구현 대상으로 본다.

### 권장 구현 순서

1. **기반:** FND-01~02와 녹화/라이브/업로드/편집 화면의 공통 상태 모델.
2. **녹화:** REC-01~07. 기존 OBS 기능과 UI 연결을 먼저 검증한다.
3. **계정·업로드:** AUTH-01~02, UPL-01~03. 홈페이지 API와 인증 계약을 확정한 뒤 연결한다.
4. **라이브:** LIVE-01~02. YouTube 연결과 동시 녹화 동작을 검증한다.
5. **편집:** EDIT-01~06. 파일 처리 엔진, 작업 저장 형식, 내보내기 경로를 먼저 설계한다.

## 3. 테스트 공통 조건

- **기본 환경:** Windows, 실제 카메라·마이크·스피커 각 1개, OBS 녹화가 가능한 권한과 여유 디스크 공간.
- **영상 데이터:** 짧은 정상 MP4 2개, 긴 MP4 1개, 손상된 파일 1개, 지원하지 않는 코덱 파일 1개, 이름이 같은 파일 1개. 영상은 소리·장면 전환이 확인 가능해야 한다.
- **계정 데이터:** 정상 계정, 잘못된 비밀번호, 만료된 세션, 홈페이지에 연결되지 않은 계정, 강좌/폴더가 있는 계정.
- **예외 환경:** 장치 분리, 녹화 폴더 쓰기 불가, 디스크 공간 부족, 업로드 중 네트워크 끊김.
- **판정:** 화면 표시만 보지 않고 실제 생성 파일·재생 결과·서버 업로드 결과까지 확인한다. 별도 표기가 없는 TC의 시작 상태는 해당 기능의 기본 화면이다.

## 5. 구현 착수 전 확정할 외부 계약

이 항목들은 화면만으로 결정할 수 없어 개발 시작 시 계정/서버 담당자와 맞춰야 한다.

1. **EduTool 인증:** 이메일 로그인 API, Google/Microsoft OAuth 사용 여부와 리디렉션 방식, 세션 갱신·로그아웃 정책.
2. **홈페이지 API:** 연결 홈페이지, 강좌/폴더 조회·생성, 파일 업로드·진행률·중복 방지, 업로드 완료 검증 방식.
3. **지원 미디어:** 입력 형식/코덱 목록, 편집 작업 파일 형식, 내보내기 형식·해상도·FPS·품질, 서로 다른 영상 합치기 정책.
4. **자동 업로드·원본 삭제:** 앱 종료 중 작업 처리, 실패 재시도, 서버 검증 완료 시점, 삭제 옵션의 기본값.
5. **라이브 계정:** YouTube 연결 및 방송 생성/선택 방식, 방송 종료와 동시 녹화 종료의 관계.

## 6. 전체 완료 기준

- 범위 내 각 작업의 연결 TC가 통과하고 실제 파일/서버 결과까지 확인된다.
- 메인화면 공통 설정 내용은 없으며 기능별 설정은 각 기능에서 접근할 수 있다.
- 오류 상황에서 녹화 원본과 편집 작업이 예기치 않게 삭제되지 않는다.
- 예시 경로·장치·계정 없이 새 Windows 사용자 환경에서 정상 실행된다.
