### 실행 파일과 배포 구성

- 실행 파일: `build_vs2022/rundir/RelWithDebInfo/bin/64bit/obs64.exe`.
- Qt Multimedia/MultimediaWidgets/Concurrent, Windows 미디어 플러그인과 FFmpeg/FFprobe를 실행 폴더로 복사하도록 CMake에 추가했다.
- 브라우저 소스는 `ENABLE_BROWSER=ON`, `CEF_ROOT_DIR=.deps/cef-bundle`로 구성했다. CEF 7871 Windows x64 공식 아카이브 SHA-256: `54cd191a3f56bb1f05be22b95e1fa8041061b38bd5fe94e0776fb34dd599f341` (저장소 고정값과 일치).
- 로컬 빌드·CEF 아카이브·스크린샷은 기존 Git 제외 경로에 유지한다. 새 기능 실행, Computer Use, 추가 스크린샷 촬영은 수행하지 않았다.
- 실제 서버는 [홈페이지 어댑터 계약](edutool-server-contract.md)에 맞춰 연결해야 한다. 현재 상태를 실제 로그인·업로드 연동 완료로 표시하지 않는다.
- 구현 커밋: 오디오 코어 `de5bfb76a`, 기능별 녹화 초기화 `7b441237b`, 편집·계정·업로드 및 화면 연결 `6c1d029dd`.
- Windows VS2022 RelWithDebInfo에서 브라우저 포함 컴파일·링크 완료. 최종 변경 후 증분 빌드 완료. 앱 실행·기능 시험은 수행하지 않았다.

아래 일자별 기록은 당시 상태를 보존한다. 모니터링 음량 미구현, 브라우저 제외, 실행 검증 재개 질문 대기는 위 최신 기록으로 대체된다.
