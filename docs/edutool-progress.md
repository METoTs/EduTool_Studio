TC 통과: **2/97 (2.1%)**. 첫 묶음은 아직 완료되지 않았다.

검증 화면은 Git 제외 폴더 `tc-screenshots/TC-001-007/`에 저장했다. 초기 화면 8장 외에 `recording-while-editing.png`, `recording-error.png`, `recording-stopped.png`를 추가했다. 첫 묶음 전체의 완료 증빙은 아직 아니다.

실제 녹화 시험: `build_vs2022/test-recordings/`에 약 44초 MP4(33,057,464바이트)를 생성했고 ffprobe에서 재생 길이를 확인했다. 재빌드 후 5초 녹화를 다시 수행해 종료 후 상단 상태가 대기로 복귀함을 확인했다. 시험은 독립된 portable 설정에서 수행했다.

화면 확인 중 발견해 수정한 문제: 편집·업로드 화면에 OBS 장면 전환 도크가 남던 문제, 해당 화면에서 종료하면 숨긴 도크 상태가 다음 실행에 저장되던 문제. 수정 후 전환 및 재실행으로 도크 복원을 확인했다.

녹화 중지 시 상단 `REC`가 남던 문제를 발견해 상태를 1초마다 재확인하도록 수정하고, 재빌드 후 중지 상태가 정상으로 돌아오는 것을 확인했다.
