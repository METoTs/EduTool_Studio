# PC 간 테마 차이 대응

## 확인한 사실

- 기존 EduTool 전용 스타일은 `frontend/data/themes/Yami.obt` 끝에만 있었다.
- 기본 테마는 Yami Original이며, 정상적인 최신 소스 및 리소스 빌드에서는 기존 방식으로도 스타일이 적용되어야 한다.
- 다른 PC의 실행 화면과 실제 소스 버전은 확보하지 않았으므로 해당 PC의 원인은 확정하지 않았다. 외부 테마 파일 교체, 사용자 테마, 다른 실행 경로 또는 이전 빌드 사용 가능성을 구분해야 한다.
- 창 크기, 도크 배치, 마지막 기능 화면은 사용자 설정에서 복원하므로 동일한 소스만으로 기존 PC의 모든 배치를 재현하지는 않는다.

## 변경

- 전용 스타일을 `frontend/forms/edutool.qss`로 분리하고 Qt 리소스로 실행 파일에 내장했다.
- 기본 테마를 적용할 때 내장 스타일을 마지막에 합쳐 외부 Yami 파일과 선택 테마에 대한 전용 스타일의 의존성을 제거했다.
- 외부 Yami 파일의 중복 전용 규칙은 제거했다. 사용자 설정이나 인증 정보는 변경하지 않는다.
- 전용 스타일은 기존 EduTool 화면과 위젯을 대상으로 한다. OBS 기본 도크를 참고 이미지와 같은 새 레이아웃으로 바꾸는 작업은 포함하지 않는다.

## 확인 범위

- RelWithDebInfo obs-studio 빌드 및 Qt 리소스 포함 여부를 확인한다.
- 다른 PC에서의 실제 화면 일치와 테마별 가독성은 별도 실행 확인이 필요하다. 이 변경으로 기존 TC 통과 수를 늘리지 않는다.
- 다른 PC에서는 이 변경을 포함한 EduTool_Studio 브랜치를 받아 다시 빌드한 후 해당 빌드의 `rundir/RelWithDebInfo/bin/64bit/obs64.exe`를 실행해야 한다.
