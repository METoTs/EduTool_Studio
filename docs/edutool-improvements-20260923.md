## 이전 설명 정정

- **모니터링 전용 음량은 이미 구현되어 있다.** `obs_source_set_monitoring_volume`, Windows WASAPI 모니터링 출력, 저장/복원 연결이 현재 코드에 존재한다. 이전의 미구현/구현 한계 설명은 오래된 기록이다. 이번 변경은 모니터링 상태 안내와 숫자 편집 안정성 개선이다. 실제 소리 분리 검증은 남아 있다.
- TC-520에 남은 TC-521 경계 재생 실패 인용은 수정 이전 기록이다. TC-521의 영상 끝까지 진행 확인은 기존 보고서에 있으며, 현재 남은 항목은 음성 경계 확인이다.
- 초기화 상태 표시는 실제 마이크 발화나 청감을 증명하지 않는다. Windows 장치 캡처 시작 성공 여부를 표시하며, 입력 내용·품질은 별도 시험한다.
- 과거 결과 파일은 이력으로 보존한다. 이후 일괄 시험의 기준은 아래 목록과 최신 하드웨어 결과 파일이다.
