## 수정 및 검증

주소 입력 후 Enter가 폴더 이동과 동시에 선택 대화상자를 닫았다. 버튼 기본 동작 해제만으로는 재현되어, 주소 입력 위젯에서 Return/Enter 이벤트가 상위 대화상자로 전달되지 않도록 보완했다. RelWithDebInfo 빌드 성공. Computer Use로 Enter 후 창 유지, 명시적 선택 후 닫힘 확인. `26-enter-keeps-browser`는 첫 수정 실패 증거이며 최종 성공 증거는 `28-enter-navigation-fixed`이다.
